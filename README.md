# Modelado Continuo

Notebooks del laboratorio de la materia Modelado Continuo: resolución numérica de ecuaciones diferenciales en Python.

| Carpeta | Contenido |
|---|---|
| `clases/` | Notebooks de cada clase de laboratorio (`01` … `07`) |
| `guias/` | Guías resueltas (`guia_1` … `guia_3`) |
| `parciales/` | Parciales: `parcial_k` es la resolución de trabajo y `parcial_k-entrega` la versión entregada |

## Temas

- **ODEs:** métodos de Euler, Heun y Runge-Kutta, y `odeint`.
- **Sistemas no lineales:** campos de direcciones y trayectorias.
- **Fourier:** series, FFT, fenómeno de Gibbs y muestreo.
- **Problemas de contorno:** diferencias finitas.
- **EDPs:** ecuación del calor.

Requiere `numpy`, `scipy`, `matplotlib` e `ipywidgets`.
